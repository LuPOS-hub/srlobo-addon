# SR.Lobo Home Assistant Add-ons

Prebuilt Home Assistant add-ons for SR.Lobo club installations.

Add this repository in Home Assistant: Settings > Add-ons > Add-on Store > ⋮ > Repositories, and paste:

```
https://github.com/LuPOS-hub/srlobo-addon
```

This repository only contains the add-on definitions. The add-ons are installed from prebuilt images; no source code is published here.
